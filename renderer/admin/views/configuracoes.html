Só ative se o XPE não abrir o relé sozinho. Usa o mesmo usuário/senha web acima.

  1. IP/porta do XPE preenchidos
  2. Usuário web do XPE informado
  3. IP LAN deste PC definido
  4. Equipamento alcançado (probe) e bridge ligado
  5. No XPE: Ações URL → Log de Acesso — cole a URL e aplique
  6. No XPE, ID Usuário = ID do paciente no AquaAccess (com foto)
  7. Firewall Windows: autorize o AquaAccess na rede privada
